# 📊 Sales Performance Dashboard

## 📌 Project Overview

This project focuses on analyzing retail sales data using Power BI to create an interactive business dashboard.

The dashboard provides insights into:
- Sales performance
- Profit trends
- Customer segments
- Category performance
- Discount impact

---

# 🎯 Objectives

- Build an interactive sales dashboard
- Monitor KPIs and business performance
- Analyze category and segment trends
- Support business decision-making

---

# 🛠️ Tools Used

- Power BI
- Python
- Pandas
- Matplotlib

---

# 📈 Dashboard KPIs

- Total Sales
- Total Profit
- Profit Margin
- Average Order Value

---

# ✨ Dashboard Features

## 🔹 Sales Trend Analysis
Visualized monthly and regional sales performance.

## 🔹 Category Performance
Compared profitability across product categories.

## 🔹 Segment Analysis
Analyzed Consumer, Corporate, and Home Office segments.

## 🔹 Discount vs Profit Analysis
Identified how discounts affect profitability.

## 🔹 Interactive Filters
Added slicers and filters for dynamic exploration.

# 📊 Key Insights

- Technology category performed best
- High discounts reduced profits
- Consumer segment generated highest sales
- Certain regions showed lower profitability
