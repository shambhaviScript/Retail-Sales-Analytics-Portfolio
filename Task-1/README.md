# 📊 Superstore Data Analysis (Task 1)

## 📌 Project Overview
This project focuses on Data Cleaning and Preprocessing (Data Wrangling) using the Superstore dataset.

The main goal of this task is to prepare raw retail sales data for further analysis by handling missing values, correcting data formats, removing duplicates, and improving overall data quality.

---

# 🎯 Objectives

- Handle missing values
- Remove duplicate records
- Convert incorrect data types
- Perform feature engineering
- Format date columns properly
- Prepare a clean dataset for analysis

---

# 🛠️ Tools & Technologies Used

- Python
- Pandas
- Jupyter Notebook

---

# 📂 Files Included

- `Task1.ipynb` → Complete data cleaning process
- `sample_store_csv.csv` → Raw dataset
- `cleaned_superstore_dataset.csv` → Cleaned dataset
